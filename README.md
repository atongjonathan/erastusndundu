# Erastus Ndundu Services — One Page Website

A lightweight, responsive, SEO-minded static website for Erastus Ndundu's furniture and interior services.

## Included
- `index.html` — semantic one-page site, metadata, Open Graph and LocalBusiness JSON-LD
- `assets/styles.css` — responsive styling
- `assets/script.js` — small progressive-enhancement script
- `assets/favicon.svg` — simple favicon
- `manifest.webmanifest` — installable web-app metadata
- `robots.txt` — crawler instructions
- `sitemap.xml` — XML sitemap
- `README.md` — setup notes

## Before publishing
1. Replace `https://example.com/` with the actual domain in:
   - `index.html`
   - `robots.txt`
   - `sitemap.xml`
2. Add the actual business/service location to the LocalBusiness JSON-LD if you want location-specific SEO.
3. Add any real social profiles to the `sameAs` array.
4. If Erastus has real work photographs, replace the Unsplash images with his own images. This is preferable for authenticity and local SEO.
5. Verify the final phone number and WhatsApp number before launch.

## Image note
The design currently references publicly available Unsplash images remotely. For production, consider downloading properly licensed images and serving optimized WebP/AVIF copies locally so page performance does not depend on a third-party image host.

## SEO notes
The page uses:
- descriptive title and meta description
- semantic headings and sections
- descriptive image alt text
- Open Graph metadata
- canonical URL
- `robots.txt`
- XML sitemap
- Web App Manifest
- LocalBusiness structured data

Structured data should only contain facts that are actually true for the business. Update the location, hours, social links and other details before publishing.
